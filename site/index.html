What does an MCA keep, and lose, on the UCI Mushroom data?

8,124 specimens, 21 categorical descriptors, one binary label. The data are almost perfectly separable, so the interesting question is not can we classify but what a five-axis MCA preserves, and which models can read it. Every score below is out-of-fold, with the MCA refitted inside each fold.

Accuracy against the number of axes kept

With five axes, the non-linear readers reach 99.3% (k-NN) and 99.8% (random forest). LDA never exceeds 88.8% with up to nine axes and needs 19 to reach 99%: five axes keep the information, but not along a straight line. With every axis, LDA reads it perfectly (100.0%), because the label is an exact linear function of the 116 indicator columns.

Which axes carry the label

η² is the share of an axis' variance explained by the edible/poisonous label. Axis 1 has η² = 0.51; axes 2 to 9 never exceed 0.09, while axis 10, with only 2.3% of the inertia, reaches 0.14, and LDA jumps when it enters. Ordering axes by inertia is not ordering them by usefulness. The data have 85 axes with non-zero inertia, not the 95 that J − Q suggests: some descriptors are exactly redundant.

The first five axes hold 31.8% of the total inertia (81.6% after Benzécri's correction).

The error that matters

For a forager, calling a poisonous mushroom edible is the only costly mistake. Odour alone is 98.5% accurate, and all 120 of its errors are of that kind (odourless poisonous specimens).

Why the earlier version of this project was wrong

The first version used scikit-learn's default cv=5, which does not shuffle. The UCI file is sorted in long same-class runs, so each fold saw a different slice of the catalogue. The spread across folds was read as an unstable model, and the random forest's train/test gap as overfitting. Re-running that protocol on the current pipeline gives LDA 81.9% ± 14.8% and random forest 85.2% ± 15.0%. With shuffled stratified folds the LDA spread drops to ±1.0% and the random forest scores 99.8%.

Limitations

The records are hypothetical specimens generated from a field guide's descriptions of 23 species, not field observations; random folds therefore test interpolation within known species, not recognition of a new one. Nothing here is advice on what to eat.

LDA uses Ledoit-Wolf shrinkage throughout. With every axis kept, scikit-learn's default LDA (SVD solver) scores 64.5%: the within-class covariance is singular exactly along the direction that separates the classes, and that solver discards it. With up to 80 axes the two solvers agree to within a few specimens.
